# Candidate 1 — honesty pass on already-demuxable audio

**Rank:** 1 (everyday audio)
**Recommendation:** **bounded child issue** if Mediabunny names WAVE PCM, MP3,
FLAC, and OGG Vorbis. Not a new decoder.

## Demand

Users bringing `.wav` / `.mp3` / `.flac` / `.ogg` hit README language that names
"video/audio" generically. WAVE PCM is already a first-party playback fixture.
That honesty gap is user friction without a new WASM payload.

bytes not in git): `pcm-s16.wav`, `mp3.mp3`, `flac.flac`, `vorbis.ogg`.

## Child issue shape

Docs, representative fixtures, and Media Pool copy only. No
`MediaDecoderPath` growth, no README format claim until that child lands with
browser evidence, no export-pair change.

## Reopen / refuse

A decoder package for these families is the wrong follow-up. If demux fails
to name a family on pinned Mediabunny, this candidate becomes no-go.
